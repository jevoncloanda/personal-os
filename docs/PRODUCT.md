# Poros

Poros is a native Kotlin/Compose Android app for local-first priorities, money, subscriptions, schedule and an entertainment library. Room records, DataStore preferences, local notifications and backup/restore supply the existing offline workflows.

The product specification governs domain behavior. Native interaction follows the UX specification. The approved Poros Stitch package governs visual identity, with dark screens first, light screens second and consolidated design prose third. The current shared tokens are recorded in DESIGN.md. [Product specification](product-specification.md) · [UX specification](ux-specification.md) · [Poros references](design/poros-stitch/README.md) · [Design system](DESIGN.md)

Poros is the user-facing brand. Existing package, database and backup identifiers persist. Financial correctness, currency meaning, schedule semantics and personal records constrain presentation changes. The redesign covers existing capabilities. Widgets, online metadata, cloud synchronization, AI and bank integrations remain outside its scope. Implementation and measured verification are recorded in the handover.
